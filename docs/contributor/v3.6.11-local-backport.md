两个环境连接同一测试机器人，必须串行运行：

```sh
# 暂停当前服务，然后运行旧版（前台）
/Users/admin/.local/bin/openclaw gateway stop --force
/Users/admin/.local/share/openclaw-compat-v3.6.11/openclaw-legacy gateway run --port 18961

# 在另一个终端检查旧版连接
/Users/admin/.local/share/openclaw-compat-v3.6.11/openclaw-legacy channels status --probe --json

# 测试结束先在旧版前台终端按 Ctrl-C，确认 18961 已停止监听，再恢复当前服务
/Users/admin/.local/bin/openclaw gateway start
/Users/admin/.local/bin/openclaw channels status --probe --json
```

源码有改动时，必须先在旧版工作区运行 `npm run build:runtime` 再启动旧版网关。
安装包位于环境根目录的 `artifacts/soimy-dingtalk-3.6.11.tgz`，是本地定制构建，不是上游原版包。
