看懂任务状态

从计划生效，到收到答案

计划已启用：已安排好未来发送，等待约定时间。

本轮执行成功：已发卡，或因上轮尚未结束而跳过本轮；以运行记录中的说明为准。成员填写和结果回传在发卡后继续进行。

收集已结束：收齐、超时或发起人取消后，向原会话回传汇总。查看汇总中的收集状态、每人回应及答案；若未收到，请检查结果投递记录。

私聊发起前：如果机器人启用了配对模式，发起人需先获得管理员批准。DWS 登录授权用于查群、查人；机器人配对决定谁能发起请求，两项授权分别管理。详见管理员准备。

触发定时“每天 / 每周 / 明天某时自动收集……”；说“帮我设计表单”只进入一次性设计。查看或暂停“查看我的定时收集”“暂停以后的项目进展收集”“恢复这个计划”。区分两种停止“删除定时计划”停止未来发送；“取消正在收集的这一张”只结束本轮。
使用边界：每张 1–50 人、1–1440 分钟，收齐即结束。名单为配置时确认的快照，不自动加入新成员。网关需要运行：重启保留未来计划，但终止未完成表单。群投放前机器人需已加入目标群；需安装支持定时收集的本地插件和 Skill。

06

收齐、到时，或者由你结束

整张表单的状态，与每个人的回应状态，是两件事。

正式收集的结束规则

正式发送→收齐回应 / 到达上限→回到发起会话

每人只接收首次提交或取消填写。所有指定成员都已回应，就提前结束；有人没回应，则等到时长上限。

  • 提交后：当前版本不支持修改已提交答案。
  • 取消填写：只代表该成员不填，也算一次回应。
  • 取消收集：发起人主动结束整张表单。
  • 放弃设计：停止当前草稿，不会创建正式表单。

07

开始前，了解这几个边界

这些规则能帮助你选对流程，也能减少误会。

群名单为什么不一定包含所有组织群？

名单来自已绑定的 DWS 账号，是该账号可读取的已加入群。它不等于组织全部群，也不代表机器人已加入这些群。真正发送还需要机器人拥有相应投放权限。

群里人很多，怎么选成员？

不超过 12 位真人成员的小群可直接勾选；更大的群会让你提供姓名或部门线索缩小范围。明确说“所有人”时按完整名单处理，单张最多 50 人。

有重名，或者有人查不到怎么办？

机器人会用真实信息辅助消歧，必要时让你选具体对象。查询权限不足、名单不完整或部分身份无法确认时，先说明原因并暂停发送，不自动挑第一位或漏掉成员。

收集期间还能继续聊天吗？

定向收集可与普通聊天、新表单并行。默认“只问当前用户”的普通表单及设计卡片仍有 5 分钟有效期，同会话新消息或新表单会使旧卡失效；草稿可在当前对话继续，按需重发设计卡。

重启机器人后，表单还有效吗？

网关或通道重启会终止未完成表单，旧答案不恢复。定时收集的计划和模板会保留，网关恢复后可执行未来轮次；设计草稿不承诺跨会话或重启恢复。

卡片说明显示不全怎么办？

现有模板的说明区可能只展示两行。设计预览把完整题目、选项和投放设置放在卡内多行区域；正式表单的说明建议简短，重要信息写进题目或明确的字段标签。

管理员准备：首次使用需要什么？
  1. OpenClaw 已接入钉钉机器人，安装支持定向表单的插件版本，并能调用表单工具；定时收集还需支持定时表单的插件版本及已启用的 OpenClaw 内置 cron。
  2. 若私聊访问采用配对模式，管理员需批准发起人在对应机器人账号下的原生配对申请。DWS 登录成功不会自动完成机器人配对。
  3. 安装本地 dingtalk-form Skill。查群、查人依赖已授权的 DWS；本说明对应 DWS 1.0.58 适配。
  4. 确认 DWS 组织与机器人组织一致，配置 Skill 的组织绑定，并为该组织指定唯一默认账号。
  5. 确认目标用户或群可被机器人触达；群投放通常需要机器人已加入目标群。查询授权不会自动带来发卡权限。

只给当前用户的默认表单不需要查询 DWS。普通使用者无需手填用户 ID、群 ID 或表单参数。
