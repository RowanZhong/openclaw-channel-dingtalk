1. 这个助手能帮你做什么 ​

代回复助手帮你把选定的钉钉来信整理成可确认的回复草稿 ，减少反复切换会话和输入重复回复。你决定监听哪些人、哪些群里的 @本人，决定回复风格，也决定什么时候发送。所有设置和确认都可以在自己的钉钉机器人私聊卡片中完成。

它适合两类工作：需要判断的消息，由 AI 起草、你看清后点发送；“正在开会，稍后回复”这类重复答复，由你提前确认固定正文、范围、有效期和频率，之后自动发送。第一次使用默认不监听，准备好后再自己开启。

功能 你能做什么 带来的好处

按对象设置回复方式 默认、联系人、群分别设置 AI 草稿、固定草稿、仅整理或不处理 不同工作关系使用不同答复要求

建议先选择一个小范围，使用“AI 起草，我确认”熟悉卡片，再为重复场景配置固定自动答复。下面的交互示意用于了解页面；实际设置请到钉钉机器人私聊完成。

2. 员工怎么用 ​

管理员安装两个配套插件、发布卡片模板并绑定本人身份后，员工在自己的钉钉机器人私聊 发送 /dws，打开代回复助手。首次默认关闭监听；安装插件不等于替所有员工开启监听。Web 主会话继续照常使用。

  1. 点「监听范围」查看三组总览，再点「设置私聊」「设置群 @本人」或「设置额外发送者」。每次只修改一组，点「校验并保存本组」后返回总览。未保存可点「取消，返回范围」。
  2. 点「回复方式」：选择「AI 起草，我确认发送」「固定正文，仍由我确认」「只整理消息」或「不处理」。可分别设置默认规则、联系人和群的要求。
  3. 回首页点「开启监听」。之后可随时暂停，设置修改无需重启 Pod。
  4. 收到审批卡或汇总卡后查看原消息、接收对象和完整回复正文 ，点「发送」即可。无需输入长审批命令。也可修改、重新拟稿、忽略，或点「我来处理」暂时暂停这个会话。
  5. 对重复性答复，点「自动答复与提醒 → 新增自动答复」，明确授权固定正文、适用范围、关键词、期限和频率。授权有效期间可直接自动发送，不再逐条确认。

第一次使用：登录与身份自检 ​

管理员完成部署后，你只需使用本人 DWS 登录。助手自动识别你的 profile 和对应机器人，不需要手填机器人开放 ID。可先在机器人私聊发送 /dws identity 查看状态。首次安装仍然默认关闭监听。

如果显示“等待 DWS 登录”，先完成平台提供的 DWS 登录/授权，再单独发送 /dws identity refresh。机器人会立即告诉你检测已在后台开始；稍后发送 /dws identity 看结果。刷新不自动开启监听，不删除已有设置和草稿。原本已经开启监听时，刷新会短暂停止并按原范围恢复；停止期间的历史消息不会补读。

“身份已就绪”说明本地绑定已通过校验；是否已经接收消息还要看 /dws-listen status 的实际状态。监听关闭时提示“机器人身份：启用监听时查询”是正常现象。身份不匹配或查询失败时，助手暂停代回复，你仍可使用普通钉钉 / Web 主会话；请按提示重新登录或联系管理员，不要把其他人的 profile 填进配置。

助手会自动识别并排除本人发出的消息及审批机器人的消息，避免把自己的回复再次生成草稿。查询的是经过核对的开放 ID，不按姓名或正文过滤。若身份查询失败，监听暂不启动，原有个人设置保留。

自动答复向导可点“上一步”修改，已填内容保留；点“取消，不授权”不会建立自动发送规则。普通设置页的“返回”不保存未提交修改。每张卡片右下角以小字显示“卡片有效期至 09/24 15:30”。这仅是本张操作卡片的截止时间，不是已保存设置、待回复草稿或自动答复授权的截止时间；时间按账户设置计算。长正文、多个对象或多条记录可能需要滚动查看，发送前请读完整内容。

普通本人主动发起的主会话请求不增加这套审批；只有本插件管理的个人 IM 监听进入该流程。

两种发送方式 ​

方式 用户操作 实际发送的内容
AI 草稿 / 固定草稿 看清卡片后点发送；或修改后发送 卡片绑定版本的完整正文，接收人固定为原会话
预授权自动答复 提前授权固定正文、范围和有效期 逐字发送已授权正文，不调用模型拼接私人资料

例如：给全部已监听私聊授权「正在开会，稍后回复你。」，有效 1 小时，同一会话间隔至少 30 分钟。命中后自动答复一次；再次来信在冷却期内不重复发送。不同答案的自动规则同时命中时，转为草稿确认。每实例每小时最多自动发送 30 条，超出后保留待确认草稿。

AI 模式不是“任意内容免审”。机器人不会自行读取文件、邮件、记忆或调用工具来补充资料。需要背景时，由本人在「重新拟稿」里为本条粘贴资料；新稿仍需确认。该资料不作为自动答复规则保存，但生成的草稿可能包含其中信息，请查看正文。

一次处理多条，减少打断 ​

首次使用默认即时提醒：草稿就绪后约 2 秒主动推送审批卡，密集来信合并，两次提醒至少间隔 10 秒；后续消息会在合并窗口结束后补发，不必等待汇总周期。只有一条待办时直接展示完整草稿与发送、修改、忽略按钮，多条则展示列表。22:00–08:00（Asia/Shanghai）免打扰；可改成定时汇总或仅主动查看。升级保留你已有的提醒选择。固定自动回复成功只进入处理记录，也可用定时汇总查看；发送结果不明会请求你核实。免打扰和提醒开关不等于暂停自动发送。系统横幅与响铃取决于钉钉通知设置。

每页显示最多 3 条，并展示各自接收对象与完整拟回复。只发送用户勾选的本页记录；不会把“全选”扩展到未来消息。不同私聊、不同群分别处理；同一条消息被多个监听规则命中只处理一次。同一会话又来新消息时，旧草稿失效，以新草稿为准。 这避免把已过时的答复发出去。

3. 监听范围和自助设置 ​

三个规则组取并集，顺序不影响最终设置。指定发送者组是额外范围，包含此人在群里未 @本人的发言；若只想监听私聊加群 @，请保持此组关闭。

规则组 可选范围
私聊 dm 关闭 / 全部私聊 / 指定单个或多个联系人
群 @本人 at 关闭 / 所有群 @本人 / 指定单个或多个群 @本人
额外发送者 sender 关闭 / 指定人员在私聊与群里的来信

每组指定 ID 最多 20 个；“全部私聊 / 所有群 @本人”不受这个名单长度限制。指定群规则会在收到群 @事件后按可信会话 ID 过滤；它不会处理这些群里所有普通消息。

人员和群怎么填 ​

  • 人员： 填钉钉 UserId，不填姓名、手机号或 DWS openDingTalkId。企业自定义工号不一定等于 UserId，拿不准时请管理员提供通讯录里的 UserId。
  • 群： 填钉钉中显示的完整群名称，例如 项目协作群。无法找到、不可见或重名都会提示，不会随意选择一个群。重名时按提示填写 完整群名#完整会话ID。
  • 多人或多群： 用英文逗号、中文逗号或换行分隔，重复项自动去重。每组最多 20 项。仅选择“指定人员/指定群”时使用下面的文本框；选择“全部”或“关闭”时忽略文本框内容。

4. 卡片不可用时的文字备用方式 ​

卡片是主要入口。网络或模板故障时，可先 /dws list 查看待处理编号，再 /dws show 23 查看第 23 条的完整草稿。机器人会返回类似：

直接复制机器人给出的短命令：/ok 23-2、/no 23-2，或 /edit 23-2 我明早确认后回复你。。23 是记录编号，2 是草稿版本，不需要自行编造。 重新拟稿或来新消息后，旧版本不能发送。/ok 23 会被拒绝，避免误发用户没看过的新正文。

如果仍收到 /approve plugin:… 通知，说明实例正在使用旧兼容审批流程：只复制该通知提供的真实完整命令，不要填写示例占位符。本文的正常流程使用卡片按钮或 /ok 编号-版本。

群内回复如何关联来信？ 人工发送、修改后发送和固定自动回复都会引用那条群消息，以你的身份回复。审批卡同时展示群、发送者和原消息。引用失败不会退回独立群消息；保留记录并提示核实。两版桌面真机已验证：原消息下方显示“1 条回复”，点开可在同一话题中查看对应回复。

5. 常见问题 ​

点击没有发送？ 查看处理记录。pending 可确认；generating 等待拟稿；superseded 表示有更新来信；unknown 表示结果需人工核实。网络故障后不要直接重发 unknown，先核对原会话。

修改范围后旧稿不能发送？ 旧稿绑定旧偏好版本，这是预期行为。重新拟稿并看清新正文后再确认。

卡片转发给别人能批准吗？ 模板禁止转发按钮，服务端还会核对真实回调用户、账号、卡片和版本，别人不能代批。

AI 会自动查询我的工作资料吗？ 不会。新助手只对明确输入做无工具拟稿。本人可为本条补充资料；整个主 Agent 的其他能力不受该插件隔离，因此仍需保留原有主会话权限管理。

卡片显示已失效？ 默认 30 分钟到期，具体截止时间显示在卡片右下角；翻页和保存不会延长。重新发送 /dws 会替换此前手动打开的操作卡；自动推送的审批卡独立管理，新提醒不会使设置页或正在输入的草稿失效。审批卡仍按自身有效期、草稿版本和处理状态校验，旧版本不能重复发送。失效只针对卡片，不会自动停止已开启的监听或到期前授权的自动答复。草稿有自己的有效期，打开新卡后可查看尚未过期的草稿。

群名旁为什么还有 ID？ 用来区分同名群。名称只帮助辨认，实际监听绑定 ID。打开卡片会自动查询缺失名称；群改名后最多可能暂存 1 小时旧名称。临时查询失败保留原名称；从未查到时显示“暂未获取名称”和完整 ID。确认网络或授权恢复后重新打开卡片即可，无需重新配置监听范围。

界面打开但监听未开启？ 先用 /dws identity 检查自动身份状态，再检查已选范围、模板 ID、DWS 授权和消费进程就绪状态。保存范围不会偷偷开启监听。

为何不用长 /approve？ 常规操作使用按钮或带版本的短命令。只有保留的旧宿主审批流程才使用 plugin 审批 ID。

6. 暂停、隐私和异常处理 ​

不想继续代回复时，在首页点击「暂停全部」，或单独发送 /dws-listen off。已经发送的消息不会撤回；下次开启会恢复已保存的范围和要求。仅关闭提醒或开启免打扰，仍可能按已授权规则自动发送。

点击「我来处理」只暂时暂停相应会话；可在暂停列表里恢复。查看「处理记录」可区分已发送、忽略、过期和结果不明。结果不明时，先查看原会话是否已收到，不要直接重复发送。

AI 草稿可能出错。发送前看清完整正文和接收对象；不要把密码、令牌或不打算分享的资料粘贴到补充资料里。不同会话分别处理，同一条来信不因命中多个监听条件而重复发送。

如卡片打不开，将发生时间、页面名称和错误提示提供给管理员；不要发送完整聊天记录或凭据。当前验收范围和已知限制见开发文档中的「真实平台验证记录」。

A.01 首页与首次启用 ​

入口： 在自己的钉钉机器人私聊中，单独发送 /dws。

首页显示个人监听开关、实际连接状态、三组监听范围、待处理数量和有效自动答复数量。“已开启（就绪）”才表示当前已具备接收条件。 如果显示“连接中”，等待后重新打开；显示“故障”时联系管理员检查，不能仅凭个人开关已开启就认为正在接收。

首页按钮 用途
查看待回复 查看待确认、仅整理、拟稿失败或结果待核实的消息
监听范围 配置私聊、群内 @本人和额外发送者
回复方式 设置默认规则及人员、群专属规则
自动答复与提醒 授权固定自动答复、设置通知、恢复暂停会话
处理记录 查看已保存的处理结果及消息详情
开启监听 / 暂停全部 改变个人监听开关；按钮随当前状态变化

首次使用按以下顺序操作：选范围并保存 → 设置回复方式 → 确认提醒方式 → 回首页开启监听 → 确认状态就绪。范围可以先保存，保存本身不自动开启监听。管理员尚未完成身份、模板或 DWS 授权配置时，先请管理员完成开通。

A.02 监听范围与对象校验 ​

入口： 首页 → 监听范围。三组范围分别保存、共同生效；任意一组命中就处理，同一条消息不会因为命中多个规则而重复生成记录。

设置页 可选项 具体含义
设置私聊 关闭、全部私聊、指定人员 只处理选定范围内发给本人的私聊
设置群 @本人 关闭、所有群 @本人、指定群 仅处理群里真正 @本人的来信；指定群也不会把普通群消息全部纳入
设置额外发送者 关闭、指定人员 额外纳入这些人的私聊和群内发言，包括没有 @本人的群消息

设置方法： 进入一组 → 选择范围 → 若选指定对象则填写文本框 → 点「校验并保存本组」。成功后返回范围总览；另外两组不变。点「取消，返回范围」不保存本页修改。监听已开启时，新设置立即应用；希望一次调整多组时，可先暂停全部再调整。

人员填 钉钉 UserId，群填完整群名称。多个对象用英文逗号、中文逗号或换行分隔，重复项去重，每组最多 20 个。选“全部”或“关闭”时无需填写名单。UserId 不一定是企业工号，不要用姓名、手机号替代。

以上都是示例，须换成企业内真实值。找不到对象、没有权限或群名重名时，页面会提示且不保存半套范围；修正后重新校验。同名群按提示填写 完整群名#完整会话ID。已保存对象再次编辑时可能显示带 #ID 的群名或 open:… 的人员值，这是保留既有绑定的形式，原样保留即可；新人员优先填写 UserId。

「校验人员或群」可单独检查对象：选择对象类型 → 输入 → 点「校验」。成功后展示名称和标识，只做校验，不会把对象加入监听。

姓名、群名会在打开卡片时自动补全；ID 用于区分同名对象。查询临时失败保留已知名称；从未查到时显示“暂未获取名称”和完整 ID。无需为此删掉并重配范围。

两个常用组合： 所有私聊 + 所有群 @本人：前两组选“全部”，额外发送者关闭。指定人员私聊 + 指定几个群 @本人：前两组分别填名单，额外发送者仍关闭。不同私聊和群分别生成、分别审批，不会把并集中的内容拼成一条回复。

A.03 回复方式与专属规则 ​

入口： 首页 → 回复方式。

处理方式 文本框填写什么 接收消息后发生什么
AI起草，我确认 语气、风格、约束等写作要求 AI 生成短草稿，通常由本人确认；若另有有效固定自动授权命中，则按授权发送固定正文
固定正文，我确认 准备发送的完整正文 逐字形成固定草稿，通常由本人确认；它本身不会建立自动授权
只整理消息 无需填写正文 记录消息，不自动拟稿或自动发送；需要回复时可主动重新拟稿
不处理 无需填写正文 不为匹配消息创建新的待回复记录，也不执行自动答复

默认规则： 点「修改默认规则」→ 选择处理方式 → 填写要求或正文 → 点「保存回复规则」。例如 AI 要求可写：用简洁、礼貌的中文回复。没有明确依据时不承诺日期；涉及决策请说明需要本人确认。

人员或群专属规则： 点「设置指定人员」或「设置指定群」→ 填入 UserId 或完整群名 → 点「校验对象，下一步」→ 核对对象 → 编辑并保存。一次填多个对象，会给每个对象应用相同规则；要分别设置不同内容，请分次操作。人员和群各最多 20 条专属规则。

匹配优先级为：任一匹配的“不处理” > 人员专属 > 群专属 > 默认。例如某群设“不处理”，即使联系人有 AI 规则，该群中的匹配消息也不会处理。专属回复规则只改变已监听消息的处理方式，不会把未监听的对象加入范围。

「恢复默认要求」把默认规则恢复为简洁、礼貌的 AI 起草；「删除专属规则」移除选定对象的覆盖规则，之后按其他匹配规则继承，不代表对该对象设“不处理”。

保存范围或回复规则后，旧草稿可能因设置版本变化不能发送；重新拟稿并看清新正文后确认即可。AI 要求最多 2000 字符，固定正文及最终回复最多 160 字符，emoji 可能占两个字符。

A.04 单条消息：审批、修改、忽略与接手 ​

入口： 主动推送的审批卡，或首页 → 查看待回复 → 选中记录 → 查看所选第一条。

先核对接收对象、发送者、原消息、当前状态和完整正文，再选择操作。单条待办通常直接推草稿详情；多条待办推列表。审批使用本人身份，消息发回原会话，不能在审批表单中换成另一个收件人。

按钮 操作结果
发送 发送当前卡片绑定的完整正文；成功后标为已发送
修改 打开正文编辑页；接收对象和原消息保持不变
发送修改后的内容 立即发送编辑框里的完整正文，不会再弹一层确认
重新拟稿 打开调整方向、补充要求和资料页面，见 A.05
忽略 本条不发送，标为已忽略；不停止该会话未来来信的处理
我来处理 进入会话暂停页，由本人选择期限后生效，见 A.10
返回首页 / 返回草稿 返回对应页面；正文编辑页返回不会保存未发送修改

只有可发送的待确认草稿显示「发送」「修改」。拟稿失败、仅整理等状态应先重新拟稿。点击后等待结果，不要反复点击；旧卡、旧版本和已处理记录不能重复发送。

群内消息会引用原来那条群消息并 @发送者。两版桌面真机均验证：原消息下方出现“1 条回复”，点开可在同一话题中查看回复。私聊直接回复原私聊。引用上下文不足或发送失败不会偷偷改成不带引用的新群消息；按显示的状态处理。

同一会话又来一条新消息： 较早未处理草稿会失效，请处理最新草稿。正在输入的编辑框不会被新通知覆盖，但提交时仍检查草稿是否过时；过时后需要返回最新草稿重新确认。

A.05 重新拟稿：调整表达与补充资料 ​

入口： 草稿详情 → 重新拟稿。

  1. 选择「按原要求」「更简短」或「更正式」。
  2. 按需填写「补充写作要求」，例如 先确认收到，说明我要核对安排，不承诺完成时间。 建议不超过 2000 字符，过长要求可能被截断。
  3. 按需填写「本人补充资料」，例如 本周可安排的时间是周四下午。 资料仅用于本条，输入最多 12000 字符。
  4. 点「重新拟稿」，等待新正文出现，再决定发送、修改或忽略。

重新拟稿本身不会发送。新稿会采用当前回复规则，并可参考本助手保存的同一会话近期消息；不会读取其他会话、工作区文件、邮件或私人记忆来补充内容。本人补充资料不会写入自动答复规则，但可能体现在草稿里，请逐字核对。

模型失败、超时或返回过长内容时，记录会显示拟稿未完成及提示；可以缩短要求后再试。模拟试拟稿命令见 A.13，它只向本人展示结果，不创建审批记录。

A.06 待回复列表与批量操作 ​

入口： 首页 → 查看待回复。每页最多 3 条，分别显示对象、原消息摘要、状态及完整拟回复。

  • 「查看所选第一条」：打开所选记录中的第一条详情，不会发送。
  • 「发送所选」：逐条检查并发送本页勾选的可发送草稿；不要勾选尚未拟稿、已经失效或结果待核实的记录。
  • 「忽略所选」：把本页勾选的可处理记录标为忽略，不发送。
  • 「上一页 / 下一页」：浏览其他记录；操作只作用于当前页选择，不包括其他页或未来来信。

不同会话各发各的正文，批量操作不会合并收件人或跨会话发送。同一批发送也可能出现部分成功、部分结果待核实，请逐条查看状态；不要因某一条异常重发整批。

A.07 固定自动答复：五步完成授权 ​

入口： 首页 → 自动答复与提醒 → 新增自动答复。适合“正在开会，稍后回复”等可以预先明确的固定答案。

步骤 需要填写或选择 说明
1/5 选择范围 全部私聊、全部已监听消息、指定人员、指定群 始终与已保存的监听范围相交；指定对象填 UserId / 完整群名，多个用逗号或换行分隔
2/5 正文 完整回复正文；可选关键词 正文最多 160 字符，逐字发送；关键词任意一个命中即可，留空表示不限制关键词
3/5 授权期限 1小时、8小时、24小时、7天 从最终确认时开始计时，默认 8 小时
4/5 发送频率 同一会话最小间隔：5分钟、30分钟、1小时、一天 默认 30 分钟；同一规则、同一会话在间隔内不重复自动发送
5/5 确认授权 核对范围、对象、完整正文、关键词、期限、间隔 点「确认授权自动发送」才真正建立授权

关键词使用文字包含匹配，不是语义判断或正则表达式；英文区分大小写。最多 10 个，每个最多 100 字符，用逗号或换行分隔。例如关键词 开会,会议 会命中包含任一词的消息。

点「上一步」可修改已填内容；点「取消，不授权」退出，不建立自动发送规则。指定多人或多群会分别建立对应规则，授权总数最多 20 条。

自动答复只有在监听开启、来信已命中范围、授权未到期、会话未暂停且回复方式允许处理时才执行。「只整理消息」「不处理」不会执行自动答复。内容固定，不让 AI 在授权正文后补充资料。

若不同正文的多条自动规则同时命中，转为草稿确认，不随意选一条发送。同一规则冷却期内显示“频率限制，本次未发”，不会在冷却结束后补发这条旧消息。实例自动发送额度为每小时最多 30 条；达到上限后保留待确认草稿。

A.08 查看、撤销和替换自动答复授权 ​

入口： 自动答复与提醒 → 查看 / 撤销授权。

每页最多 5 条，显示适用对象、有效至或已到期、完整固定正文。勾选本页规则后点「撤销所选授权」。撤销只影响所选规则的后续自动发送，不撤回已经发出的消息。

需要修改授权正文、对象或期限时，先撤销旧授权，再走五步向导建立新授权。当前页面没有原地编辑授权按钮；不要为了改一句话而同时保留两条不同正文的重叠规则。

“有效自动答复”数量只统计未到期规则；管理列表可能保留已到期规则。额度已满时可撤销不再需要的规则。关闭提醒不等于撤销授权，想停止所有代回复请暂停全部监听。

A.09 提醒方式、汇总、免打扰与重点联系人 ​

入口： 自动答复与提醒 → 提醒设置。四个子页分别保存；改一项不会覆盖其他项。

子页 可选值 / 填写方式 保存后的效果
提醒方式 即时提醒、定时汇总、仅主动查看 即时默认草稿就绪后约 2 秒推卡；汇总按间隔提醒；仅主动查看不主动推送
汇总间隔 5分钟、15分钟、30分钟、1小时 仅在定时汇总模式生效，默认 15 分钟
免打扰时段 开始、结束时间均为 HH:MM；时区如 Asia/Shanghai 默认 22:00–08:00；可跨午夜；起止相同表示关闭免打扰
重点联系人 UserId，可用逗号或换行分隔，最多 20 人 非免打扰时段优先及时提醒；留空并保存可清空名单

各子页点「保存本项」生效；直接返回不保存。重点联系人仍受“仅主动查看”和免打扰约束，不会强行突破关闭提醒的选择。结果待核实也会在允许推送时优先提醒。

即时模式会把密集来信合并，两次提醒至少间隔 10 秒；新到消息会在后续合并窗口补推。时间从草稿就绪起计算，模型拟稿、网络投递或已有通知等待会增加从来信到看到卡片的总时间。

单条待办直接显示草稿详情，多条显示待处理列表。自动答复成功在即时模式只进入历史；定时汇总可展示历史变化。免打扰结束后恢复尚待提醒内容，随时仍可 /dws 主动查看。系统通知横幅和提示音由钉钉客户端设置决定。

提醒不控制发送： 仅主动查看、免打扰都不会暂停已授权的固定自动答复。希望完全停止代回复，应使用首页「暂停全部」。

A.10 暂停全部与暂停单个会话 ​

需求 操作 对现有草稿与后续消息的影响
暂停全部监听 首页「暂停全部」，或 /dws-listen off 停止接入新消息；已保存草稿仍保留，但暂停时不能批准发送
恢复全部监听 首页「开启监听」，或 /dws-listen on 按已保存范围和要求恢复；已到期授权不会因此延长
自己接手一段时间 草稿「我来处理」→ 选期限 →「我来处理并暂停」 暂停该私聊或群会话，并忽略该会话现有待处理草稿
提前恢复一个会话 自动答复与提醒 → 暂停的会话 → 勾选 → 恢复所选 取消所选会话暂停；不自动重发旧消息

会话暂停可选 1 小时、8 小时、一天、直到手动恢复，默认 8 小时；有期限的暂停到期后恢复处理。暂停列表每页最多 5 个。群会话暂停作用于整个群会话，不是只暂停本条消息的发送者。

暂停不是撤回，已经发送的消息保持原样；如果点击暂停前发送已经开始，不能保证取消在途发送。停止后再开启不会主动读取并补处理停用期间的历史消息。本人直接在原会话手动回复，不等于已经通知助手暂停；需要接手时请用「我来处理」。

A.11 处理记录与全部状态说明 ​

入口： 首页 → 处理记录。每页最多 3 条，勾选后「查看所选第一条」可打开详情；这里用于查看，不提供整页批量发送。

卡片状态 含义 下一步
正在拟稿 AI 仍在生成 等待更新，再查看正文
待确认 有可供本人确认的完整草稿 发送、修改、重新拟稿、忽略或接手
仅整理 已记录消息，尚无回复草稿 若需要回复，点重新拟稿
有新消息，需刷新 记录需要按最新状态处理 刷新并核对最新消息或重新拟稿
拟稿未完成 模型调用或正文校验未成功 查看提示，调整要求后重新拟稿
发送中 已开始投递 等待，不要重复点击
已发送 已取得成功回执 需要时到原会话核对
发送结果待核实 无法确定对方是否已经收到 先检查原会话；助手不会自动重发
已忽略 已决定本条不发 后续新来信仍按规则处理
已过期 已超过草稿有效期 在原会话自行处理，不能靠重开卡延长
已有更新草稿 同会话有更新来信，较早草稿已失效 查看最新草稿
频率限制，本次未发 自动答复处于同规则会话冷却期 本条不会延迟补发，可自行处理

已发送、忽略、过期、被替代和被频率限制的记录通常保留最近 30 天；历史列表不是永久聊天归档。待处理及结果不明记录不会按上述已完成记录的规则直接清理。不能在历史中把已发送或已忽略记录再次批准发送。

A.12 四种时间、卡片更新与设置保存 ​

项目 默认或可选时间 到期或变化意味着什么
操作卡片 默认 30 分钟，管理员可调整 仅当前卡片失效；重新 /dws 获取新操作卡
回复草稿 默认 24 小时，管理员可调整 草稿不能继续发送；重开卡或重新拟稿不重置原草稿到期时间
自动答复授权 本人选 1 / 8 / 24 小时或 7 天 停止这条规则的自动发送
会话暂停 本人选期限或手动恢复 暂停结束后恢复后续消息处理，不补发旧消息

卡片右下角的小字“卡片有效期至 MM/DD HH:mm”只指该卡片，时间按提醒设置里的时区显示，精确到分钟。页面跳转、保存、翻页不延长截止时间。

再次发送 /dws 会使此前手动打开的操作卡停用；自动推送的审批卡与操作卡独立管理，不会因为新提醒到达而冲掉设置页或正在输入的正文。即使卡片本身没到期，草稿版本、处理状态或设置版本变化后，旧按钮也可能被拒绝；重新打开最新页面即可。

个人监听开关、范围、回复规则、提醒和授权会保存到自己的实例。管理员保留持久化存储、账号绑定不变时，重启后继续读取个人设置；首次部署的默认关闭值不会覆盖已经保存的个人选择。授权及暂停按实际截止时间计算，不因重启延长。卡片输入但未保存的内容不属于已保存设置。

A.13 完整快捷命令与试拟稿 ​

所有命令都在本人机器人私聊里单条发送，不在群里执行。下面的 <…> 是占位说明，使用时替换为真实值并去掉尖括号。例子中的 23-2 也必须替换为机器人展示的真实编号和版本。

打开、查看和审批：

命令 用途
/dws 打开新的助手操作卡
/dws identity 查看当前账号、机器人身份、缓存与故障状态，不发起查询
/dws identity refresh 后台重新检测身份，沿用个人监听开关，随后用 identity 查看结果
/dws list 查看最多 10 条文字待处理记录；更多记录用卡片翻页
/dws show 23 查看第 23 条的原消息、完整草稿及当前版本
/ok 23-2 批准发送第 23 条、第 2 版草稿
/no 23-2 忽略对应版本，不发送
/edit 23-2 新的完整正文 直接发送替换后的完整正文，不是只保存草稿

监听开关与范围：

命令 用途
/dws-listen help 查看命令帮助
/dws-listen status 查看开关、实际就绪状态、范围和消费进程数
/dws-listen on / /dws-listen off 开启 / 暂停监听
/dws-listen dm all / /dws-listen dm off 全部私聊 / 关闭私聊组
/dws-listen dm users <U1,U2> 指定私聊人员
/dws-listen at all / /dws-listen at off 所有群 @本人 / 关闭群 @组
/dws-listen at groups <G1,G2> 指定群内 @本人
/dws-listen sender users <U1,U2> 额外监听指定发送者，包括群内未 @发言
/dws-listen sender off 关闭额外发送者组

文字命令的 U1,U2 是 openDingTalkId（用户开放 ID），G1,G2 是 openConversationId（群会话 ID），多个 ID 用英文逗号分隔，不加空格。它们与卡片里填写的 UserId、完整群名不同。没有开放 ID 时，优先用卡片完成校验，不要把姓名或企业工号填进命令。

回复规则与模拟试拟稿：

命令 用途
/dws-reply help 查看帮助
/dws-reply status 查看默认、人员、群专属规则摘要
/dws-reply show default 查看完整默认要求
/dws-reply show user <U1> / /dws-reply show group <G1> 查看指定对象已保存规则
/dws-reply default ai <写作要求> 默认 AI 起草
/dws-reply default fixed <完整正文> 默认固定草稿，仍需确认
/dws-reply default inbox / /dws-reply default off 默认只整理 / 不处理
/dws-reply default reset 恢复默认 AI 要求
/dws-reply user <U1> ai <要求> / /dws-reply group <G1> fixed <正文> 设置指定对象；user、group 都支持 ai、fixed、inbox、off
/dws-reply user <U1> reset / /dws-reply group <G1> reset 删除专属规则，恢复继承
/dws-reply preview default <模拟消息> 按默认规则试拟稿，仅展示给本人
/dws-reply preview user <U1> <模拟消息> / /dws-reply preview group <G1> <模拟消息> 按该单类对象及默认规则试拟稿，不模拟人员与群同时命中的组合

模拟消息最多 4000 字符。试拟稿不发给联系人或群，不创建审批，不测试监听是否收到真实消息，也不创建自动授权。AI 试拟稿需要宿主提供命令侧模型接口；提示不支持时可查看固定正文预览，或请管理员检查。

自动答复五步授权、提醒和会话暂停使用卡片入口，当前没有同等的 /dws-auto 命令。若使用旧兼容流程收到 /approve plugin:…，只复制通知里的真实审批 ID，不要输入示例占位符。

A.14 三个可直接参考的工作场景 ​

场景一：忙时整理全部私聊和群 @，每条自己决定。 私聊选全部、群 @选所有群、额外发送者关闭；默认回复选 AI 起草；不创建自动授权；提醒选即时。来信产生草稿，看清后发送，复杂内容用重新拟稿补充资料。

场景二：只代处理项目群和指定同事。 私聊选指定人员并填 UserId，群 @选指定群并填完整群名；额外发送者保持关闭。给项目群设置“只确认收到，不承诺排期”的 AI 要求；给某些同事设置专属要求。不同群、私聊的草稿分别审批。

场景三：开会一小时，少打扰但让同事知道已收到。 先确认需要处理的私聊已在监听范围，回复方式允许处理；新增自动答复，范围选全部私聊，正文填 正在开会，稍后回复你。，关键词留空，有效期选 1 小时，同会话间隔选 30 分钟；核对后确认授权。提醒可改为定时汇总或仅主动查看；会后可提前撤销授权。群 @消息不因这条“私聊”授权自动发送。
